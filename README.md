# 📘 BudgetBook

**BudgetBook** is a simple and lightweight CLI application for tracking incomes and expenses.  
It is designed as a personal learning project to practice C# development, software architecture (arc42), and version control workflows.

---

## Features

- Record incomes and expenses via command-line interface
- Automatically store transactions in a local JSON file
- View today's transactions in a table format
- Extendable for GUI, report generation, and monthly statistics

---

## 🛠️ Technologies

- **Language:** C# (.NET 8.0)
- **Architecture:** Modular (based on arc42)
- **Persistence:** JSON file storage
- **CLI:** Console-based interaction

---
